# CodeAlpha_Login_System (C++)
 
## Description
This project allows users to register and log in using a username and password stored in a file.

## Features
- User registration
- Login authentication
- File storage for credentials
- Error handling for wrong login

  ## Technologies Used
  - C++
  - File Handling
 
    ## How To Run
    - Compile: g++ login.cpp -o login
    - Run: ./login
