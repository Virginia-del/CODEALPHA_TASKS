# CGPA Calculator (C++)

## Description
This project is a simple C++ program that calculates a student's CGPA based on grades and credit hours entered by the user.

## Features
- Accepts number of courses
- Takes grade (A-E) and credit hours
- Calculates total grade points
- Displays final CGPA

# Technologies Used
- C++

## How to Run
1. Compile the program: g++ cgpa.cpp -o cgpa
2. Run: ./cgpa

## Example
Enter number of courses: 3
Enter grade for course 1: A
Enter credit hours: 3

CGPA: 4.0
